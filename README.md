## 🎯 Возможности

- **Парсинг категорий** – автоматический обход всех страниц каталога с поддержкой пагинации
- **Сбор сайтов** – извлечение URL компаний из HTML-блоков и структурированных данных (JSON-LD)
- **Декодирование ссылок** – поддержка base64-закодированных URL
- **Обогащение контактами** – поиск email, телефонов, соцсетей (Telegram, WhatsApp, VK) на сайтах компаний
- **Умный поиск** – приоритетная проверка контактных страниц, минимизация количества HTTP-запросов
- **Обработка редиректов** – корректная работа с HTTP 301/302
- **Тестовый режим** – быстрая проверка на ограниченном объёме данных (1 компания с категории, 1 контакт с сайта)
- **Защита от дублей** – автоматическая дедупликация записей при повторных запусках
- **Пагинация** – автоматическое определение и обход следующих страниц (page-2, page-3...)
- **Многопоточность** – поддержка нескольких входных файлов
